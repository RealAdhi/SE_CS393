## Epics & User Stories (from Lab 1 — Municipal Solid Waste Route Optimizer)
| Epic | Story | Priority | Story Points |
|------|-------|----------|--------------|
| EPIC-1 Route Generation | As a supervisor, I want routes with only bins >= 80% full, so that trucks avoid wasted trips | High | 8 |
| EPIC-1 Route Generation | As a supervisor, I want to review/edit/approve a route, so that local exceptions are handled | High | 5 |
| EPIC-2 Driver Execution | As a driver, I want to mark bins Collected/Skipped/Inaccessible with a reason code, so that exceptions are recorded | High | 5 |
| EPIC-3 Citizen Complaints | As a citizen, I want to file a missed-pickup complaint, so that it is linked to the stop and driver status | Medium | 5 |
| EPIC-4 Fleet Resilience | As a supervisor, I want routes recomputed when a truck is out of service, so that no zone loses service | Medium | 8 |

## Sprints
Sprint 1 (1 week): stories in EPIC-1 and EPIC-2 (18 pts). Sprint 2 (1 week): EPIC-3 and EPIC-4 (13 pts).

## Reflection (mock answers)
1. Estimates were roughly right; the route-recompute story was the most underestimated.
2. Backlog prioritisation followed user impact: generation and driver flows first.
3. Sprint 1 matched the plan closely; Sprint 2 slipped by about one story.
4. The burndown showed a flat start then a steep drop late in the sprint, suggesting work should be broken down further.
